# Incident & Real Failure Log

This log records genuine failures and issues encountered during development, testing, and deployment.
Each entry documents:
1. **Date & Time**
2. **Symptom / What Broke**
3. **Detection Mechanism**
4. **Root Cause Analysis**
5. **Resolution / Fix**
6. **Preventative Measures Taken**
